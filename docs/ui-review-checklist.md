# UI review checklist

- [ ] Pages UI loads `api/v1/catalog.json`
- [ ] Work件数が正準APIと一致する
- [ ] Kindle購入Workが検索・登録元フィルターに出る
- [ ] 著者検索が機能する
- [ ] 適用中フィルターチップを個別解除できる
- [ ] 820px以下でフィルターが初期折り畳みになる
- [ ] グリッド / リスト表示がURLに保持される
- [ ] ページ送りに前後・省略表示がある
- [ ] Work詳細にEdition / Holding / Acquisitionが分離表示される
- [ ] Sample / PrimeがHoldingとして表示されない
- [ ] ISBN / ASINがEdition識別子として区別される
- [ ] 320px幅で横スクロールが発生しない
- [ ] キーボード `/` で検索欄へ移動できる
- [ ] prefers-reduced-motionを既存CSSから継承する
