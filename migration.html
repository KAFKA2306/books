KKAFKA BOOKSLibrary migration diagnosis 本棚へ戻る

LOCAL / DRY-RUN / NO UPLOAD

蔵書データを、書き込む前に診断。

CSV・JSON・ISBN一覧を選ぶと、現在のKAFKA BOOKSと同じISBNチェック・正規化書名・batch重複・類似作品ルールでブラウザ内診断します。

蔵書内容は外部送信しません。選択したファイルはこのページのメモリ内だけで処理します。公開catalogの取得以外にネットワーク送信は行いません。

無料診断

  1. CSV・JSON・ISBN一覧を選択
  2. 「診断する」を押す
  3. 必要ならJSON / HTMLを保存

CSV / JSONは title, isbn（または isbn13 / isbn10）, source, status, price, purchase_date の部分集合に対応します。ISBN一覧は1行1ISBNのテキストです。

サンプルは架空の2件だけを使い、公開catalogに対して同じdry-run診断を実行します。
